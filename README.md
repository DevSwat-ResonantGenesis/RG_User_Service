## Quick Start
```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Deployment
- **Container**: `user_service` | **Port**: 8000
- **Server path**: `/home/deploy/RG_User_Service`
